# Rift Wizard 3 한국어 번역 — 삼도리버

## 설치

1. 이 모드의 최신 버전을 다운로드 받습니다.

<img width="497" height="401" alt="image" src="https://github.com/user-attachments/assets/140c11ea-286d-49e3-9643-13e3fa5f28d8" />

2. 스팀의 라이브러리에서 Rift Wizard 3를 우클릭 -> 관리 -> 로컬 파일 탐색

<img width="583" height="406" alt="image" src="https://github.com/user-attachments/assets/b0c76ecb-9dcb-4495-8085-f72e184fd2a9" />

3. 다운로드 받은 파일의 압축을 해제하고, mods폴더에 넣습니다.

**중요** 
압축 해제된 폴더를 열었을 때 Core폴더가 바로 보여야합니다. RW3KoreanSanzuRiverr 폴더가 보인다면 해당 폴더를 mods폴더에 넣으세요.
혹시 폴더 이름에 -main이 보인다면 지워주세요. 폴더명이 RW3KoreanSanzuRiverr으로 돼있어야 정상인식 됩니다.

4. 메인 메뉴에서 MODS를 클릭합니다.
5. RW3KoreanSanzuRiverr 모드를 ENABLED에 놓습니다.
6. 게임을 재시작하고, OPTIONS -> Language Select 에서 한글을 선택합니다.

## 기능
1. 자동 번역 누락 감지.
riftwizard3는 아직 개발중으로, 업데이트에 따라 새로운 번역이 필요한 문구가 추가될 수 있습니다. 이 모드에서는 미번역 텍스트를 자동으로 감지해서 모드 내에서 번역을 추가할 수 있는 기능을 지원합니다. 또한 이렇게 추가된 번역은 택스트 형태로 공유해서 추가적인 모드 업데이트 없이도 커뮤니티가 번역을 관리 가능합니다.
(문자의 조합에 의해 동적으로 생성되는 텍스트에서는 해당 기능이 부정확할 수 있습니다.)
2. 한국어 입력/검색 관련 각종 편이 기능 추가

## 게임 안에서 누락 번역 입력하기

누락 감지의 기본값은 번역 누락 감지 안 함입니다. 이 모드는 새 누락을 검사·수집하지 않습니다.
번역 누락을 수정하려면 "번역 누락 감지 시 즉시 번역하기" 또는 "번역 누락 감지 시 저장해두기"를 선택하세요.
번역 추가의 편의를 위해 추천 번역 기능을 연결해뒀으니 참조하면 됩니다.

**누락 번역은 https://www.youtube.com/watch?v=-bTBhu6XwvU 영상의 댓글에 남겨주시면 이후 모드 업데이트에 참조해서 수정하겠습니다.**

## 크레딧

기존 KoreanLocalization의 일부 번역을 참조했습니다. KoreanLocalization모드의 기본이 된 일본어화 MOD역시 감사의 말을 드립니다.

##폰트에 대하여

나눔고딕 Bold 폰트를 사용했습니다.

##면책 조항

이 모드는 유저가 제작한 비공식 한국어화입니다.
- 오역, 미번역, 버그 등에 대해 제작자는 일체의 책임을 지지 않습니다. 이용은 자기 책임으로 부탁드립니다.
- 본 모드 사용으로 발생한 어떠한 손해에 대해서도 제작자는 책임을 지지 않습니다.
- 본체나 게임 업데이트로 인해 동작하지 않게 될 수 있습니다.
이상에 동의한 후 이용해 주세요.
