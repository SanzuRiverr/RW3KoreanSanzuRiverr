# Rift Wizard 3 한국어 번역 — 삼도리버

버전 0.8.4 · 모드 식별자 RW3KoreanSanzuRiverr

## 설치

1. 게임을 종료하고 `RW3KoreanSanzuRiverr` 폴더를 게임의 `mods` 폴더에 넣습니다.
2. 게임을 실행하고 Mods 메뉴에서 이 모드를 활성화합니다.
3. 게임을 완전히 종료했다가 다시 실행하고 언어 설정에서 한국어를 선택합니다.

## 기능

1. 자동 번역 누락 감지.
riftwizard3는 아직 개발중으로, 업데이트에 따라 새로운 번역이 필요한 문구가 추가될 수 있습니다. 이 모드에서는 미번역 텍스트를 자동으로 감지해서 모드 내에서 번역을 추가할 수 있는 기능을 지원합니다. 또한 이렇게 추가된 번역은 텍스트 형태로 공유해서 추가적인 모드 업데이트 없이도 커뮤니티가 번역을 관리 가능합니다. (문자의 조합에 의해 동적으로 생성되는 텍스트에서는 해당 기능이 부정확할 수 있습니다.)
2. 한국어 입력/검색 관련 각종 편의 기능 추가

## 게임 안에서 누락 번역 입력하기

누락 감지의 기본값은 번역 누락 감지 안 함입니다. 이 모드는 새 누락을 검사·수집하지 않습니다.
번역 누락을 수정하려면 "감지된 번역 누락 즉시 수정하기" 또는 "감지된 번역 누락 저장해두기"를 선택하세요.
번역 추가의 편의를 위해 추천 번역 기능을 연결해뒀으니 참조하면 됩니다.

## 크레딧

기존 KoreanLocalization의 일부 번역을 참조했습니다. KoreanLocalization모드의 기본이 된 일본어화 MOD역시 감사의 말을 드립니다.

## 폰트에 대하여

나눔고딕 Bold 폰트를 사용했습니다.

## 면책 조항

이 모드는 유저가 제작한 비공식 한국어화입니다.
- 오역, 미번역, 버그 등에 대해 제작자는 일체의 책임을 지지 않습니다. 이용은 자기 책임으로 부탁드립니다.
- 본 모드 사용으로 발생한 어떠한 손해에 대해서도 제작자는 책임을 지지 않습니다.
- 본체나 게임 업데이트로 인해 동작하지 않게 될 수 있습니다.
이상에 동의한 후 이용해 주세요.
